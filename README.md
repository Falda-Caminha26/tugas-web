# Aplikasi Pengelola Keuangan Sederhana (Pemecahan Masalah Sehari-hari)

Tugas Mandiri - Pemrograman Web (Pertemuan 1-3)

## Deskripsi Program
Aplikasi ini dibuat menggunakan kombinasi HTML, CSS, dan JavaScript untuk membantu pengguna memantau keuangan harian mereka. Program ini menyelesaikan masalah umum sehari-hari: melacak sisa uang belanja berdasarkan pemasukan dan pengeluaran yang diinput secara real-time.

## Anggota File
1. index.html - Struktur formulir input pemasukan dan pengeluaran.
2. style.css - Desain antarmuka responsif dan minimalis.
3. script.js - Logika penambahan data pengeluaran dan kalkulasi sisa saldo otomatis.
